ER Diagram — Volt Debt

PostgreSQL schema จาก backend/app/schema.sql · 4 schemas: landing (ข้อมูลนำเข้า) · records (ความจำของผลิตภัณฑ์) · app (state ต่อ session) · audit (append-only)

landing — เขียนโดย import run, อ่านโดย book_source records — durable, ไม่ถูกล้างตอน deploy app — ต่อ session, หายตอน deploy audit — append-only (trigger ห้าม UPDATE / DELETE / TRUNCATE)
